# coffmans.github.io

Personal site for Shawn Coffman, hosted on GitHub Pages at https://coffmans.github.io.

Hand-built with plain HTML, CSS and a little JavaScript, with no framework or build step.

- `index.html`: the whole page
- `assets/css/style.css`: styles, including the light/dark theme tokens at the top
- `assets/js/main.js`: theme toggle, mobile menu, scroll effects, and the auto-updating year counts
- `assets/files/Shawn-Coffman.pdf`: portfolio / résumé

To preview locally, run `python -m http.server 5500` and open http://localhost:5500.

Icons are from Font Awesome Free (CC BY 4.0).
